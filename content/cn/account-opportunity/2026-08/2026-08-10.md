## 买家避坑

1. 在 Claude Code 或其他第三方 IDE 里接入 OpenAI API key 之前，先到 OpenAI 官方帮助中心确认当前允许的第三方集成场景；不要只看卖家说明，「卖家说可以用」和「条款允许」是两件事。
2. 社交平台上的封号故事经常缺截图和时间线，购买前问清楚卖家：账号是哪个区域注册、是否绑定官方支付方式、当前使用场景是否符合平台条款。
3. 如果卖家承诺某种用法「官方教程里提过所以不会封」，要求他给出具体条款页链接；教程里提过某个用法，和条款明确允许，是完全不同的两件事。
