## 今日可执行
### 给 Claude 订阅商品增加「AI 自主研究场景上手说明」
**判断：** 这是 Anthropic 展示的研究能力，不是面向普通用户的新套餐或功能更新，但它可以帮助现有 Claude 订阅卖家向需要文献检索、方案生成、数据处理场景的买家演示 Claude 在完整研究流程中的实际可用范围。

- **证据与可信度：** [Anthropic 官方研究页面：证明 Claude 自主研究能力及成本数据](https://www.anthropic.com/research/automated-researchers-mitigate-alignment-failures)、[Anthropic 官方论文 PDF：证明研究方法和结果细节](https://www-cdn.anthropic.com/7b1c44894e98087a6479947dcdd40716278aeeffd/automated-alignment-researchers-august-2026.pdf)；可信度：高；证据缺口：研究论文没有说明普通 Claude 订阅用户能否直接复现同样的自主研究流程，也没有公布实际 API 调用量和费用明细。
- **供给形态：** 账号加教程或售后说明。这是给现有 Claude 官方订阅商品增加的场景教程，不是独立商品，也不是新套餐。
- **适合买家与真实需求：** 需要处理文献检索、方案生成、数据清洗、实验设计等完整研究流程的学生、研究员或小团队，想知道 Claude 订阅能否替代部分人工研究环节，以及实际成本和效果边界。

- **今天最小动作：** 用自己的 Claude Pro 或 API 账号测试一个完整的小型研究场景（例如查 3-5 篇论文摘要、生成一份方案大纲、清洗一份小数据集），记录实际可用功能、耗时、API 调用量和费用，整理成一页「AI 自主研究场景上手说明」，写清哪些环节可以直接用、哪些环节需要人工介入、实际成本和 Anthropic 研究论文的差异。
- **售后与合规：** 售后风险：中；Anthropic 研究论文展示的是受控实验环境下的自主研究能力，普通 Claude 订阅用户可能无法直接获得同样的自主任务编排和长时间运行能力；如果买家期望 Claude 能像论文中那样完全自主完成复杂研究任务，可能会因为实际可用范围、API 费用或任务中断问题要求退款。交付说明必须写清：这是基于当前 Claude 订阅的场景演示，不是 Anthropic 研究论文中的完整自主研究系统；实际 API 调用费用和任务复杂度可能导致成本高于 4 美元时薪；复杂任务可能需要人工分段提示和中间检查。
- **不能承诺与停止：** 不能承诺 Claude 订阅用户能够复现 Anthropic 研究论文中的完整自主研究流程，也不能承诺 4 美元时薪或超过人类研究员的质量。48 小时内如果实际测试发现 Claude 在文献检索、方案生成、数据处理等场景中无法完成基本任务、API 费用明显超出预期、或买家询问集中在「为什么不能像论文里那样自主完成」，立即在商品说明中补充实际可用范围和成本差异，或暂停这个增值交付；如果测试顺利、买家询问集中在具体场景配置和成本核算，继续完善上手说明并附加到现有 Claude 订阅商品中。

## 买家避坑
- 核对卖家提供的 Claude 订阅类型（Pro / Team / API）和实际可用功能范围，Anthropic 研究论文展示的自主研究能力不等于普通订阅用户能直接使用的功能。
- 询问卖家是否提供实际场景演示或录屏，特别是文献检索、方案生成、数据处理等完整流程的真实可用范围和人工介入点；如果卖家只提供研究论文截图或媒体报道，要求补充实际测试结果。
- 如果需要长时间运行的自主研究任务，核对 Claude API 的实际调用费用和速率限制；Anthropic 研究论文中的 4 美元时薪是受控实验环境下的成本，普通用户的实际 API 费用可能因任务复杂度和调用频率明显偏高。
