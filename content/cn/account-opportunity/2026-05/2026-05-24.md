## 今日主推

### [Codex 额度重置 → 今天先挂「代跑通 + 配置说明包」](https://imjuya.github.io/juya-ai-daily/issue-100/)

Codex 刚修复额度异常、重置限额，这批重置用户里有一部分人今天会重新打开，发现还是不知道怎么配、怎么接、跑不起来。这个窗口很短，今天挂比明天挂值。

你不用卖账号，卖的是「帮他跑通这一步」——代配置、交付说明、答疑一次。买家拿到的是能用的状态，不是一个账号链接。

- 发生了什么：Codex 修复额度消耗异常并重置所有限额，短期内重新激活一批想试用但卡在配置的用户
- 证据来源：[橘鸦AI早报 2026-05-24](https://imjuya.github.io/juya-ai-daily/issue-100/)
- 可信度：中
- 是否今天能挂闲鱼：是
- 今天先挂什么：「Codex 代配置 / 跑通服务」，标题写交付结果，不写 SDK 名词
- 今天先测什么：发一版私聊或社群说明，限定只做「帮你跑通第一次」，看有没有人问
- 售后风险：低
- 今天最小动作：写一版 3 句话的服务说明：我帮你配好、跑通、截图交付，今晚先发社群或朋友圈试一下

## 平替机会

- **DeepSeek 平替组合体验包**：V4-Pro API 永久低价落地，[橘鸦早报 2026-05-23](https://imjuya.github.io/juya-ai-daily/issue-99/) 有确认。今天可以挂「GPT + DeepSeek 双模型对照体验包」，卖点是先试再定、不用押注一个。标题写「两个模型同一个问题，你自己选哪个更好用」，售后风险低，今天就能上

- **Claude 账号 + PPT 场景搭售包**：[Twitter 上 Opus 4.7 vs ChatGPT 的 PPT 对比](https://x.com/Gorden_Sun/status/2057847013291757974) 已经有人在传，买家今天有具体场景可以对号入座。卖法：Claude 账号 + 一页 PPT 生成场景说明，标题写「做 PPT 不用自己排版，Claude 帮你出初稿」，搭售利润款，售后边界清楚

- **DeepSeek 迁移说明包**：有人从 GPT/Claude 往 DeepSeek 迁，但不知道 API 怎么换、提示词要不要改。做一个「从 GPT 迁到 DeepSeek 的 5 步说明」，卖迁移包而不是账号，售后极低，今天就能发

- **Codex 额度重置 → 平替入口筛选**：重置后有人会发现 Codex 还是不够用，这时候需要备用入口。可以挂「Codex 不够用时的 3 个平替入口清单」，轻服务，卖的是你帮他排过坑
