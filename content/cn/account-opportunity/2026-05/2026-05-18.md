# 今日AI账号商机

## 先看信号

- Codex / Claude Code 的非编程玩法正在被 OpenAI 工程师自己示范：跟进任务、做 PPT、处理报销——这批用法正在从开发者圈往外溢，买家会开始问"我也能用吗"
- Anthropic 官方刚发 Skill 构建指南，有人已经做了双语版，Claude Code 的上手门槛话题热度在升
- 微信读书 Skill 跑通教程在 X 上传播，涉及 API key 获取步骤，有一定配置门槛，小白会卡住
- 今天没有明显封号或支付波动信号，账号直卖需求平稳，轻服务和跑通包是今天更值得测的方向

## 平替机会

- **Claude Code 跑通包**：Anthropic 刚发官方 Skill 构建指南，有人做了双语版，但大多数人还是不知道怎么配。可以卖"Claude Code 上手包"——交付内容：双语指南整理 + 1 个场景配置说明 + 答疑。比直卖账号多一层价值，售后边界也更清楚。证据：[Anthropic官方Skill构建指南双语版](https://m.okjike.com/originalPosts/6a09ecad2eed1eea612179da)

- **微信读书 Skill 代配置**：微信读书 Skill 的安装教程已经在传，但涉及 API key 获取、npx 命令、Codex/Claude Code 接入，小白会卡在任意一步。可以卖"帮你把微信读书 Skill 装好"的代配置服务，交付：跑通截图 + 操作说明。注意：今天先私聊或社群试水，不建议直接挂闲鱼（售后风险高，步骤多容易出问题）。证据：[微信读书Skill安装配置教程](https://x.com/vista8/status/2055830488011735519)

- **多模型对照体验包**：今天素材里同时出现了 Codex（OpenAI）和 Claude Code（Anthropic）的用法讨论，还有人提到 Gemini 写作好用。可以做一个"三模型写作/任务场景对照体验包"——买家买的是对比感受，不是死绑一个模型。低价引流款，今天就能试挂。

## 今天别碰

- **微信读书 Skill 直接挂闲鱼公开卖**：步骤多（API key + npx + Codex/Claude Code 接入），任何一步出问题买家都会来找你，售后风险高。今天先私聊或社群小范围试，摸清楚哪步最容易卡，再决定要不要公开挂。

- **把 gstack（Garry Tan 的 Claude Code 配置）包装成成品卖**：这是开源项目，23 个角色配置，听起来很酷，但买家拿到不知道怎么用，售后会很重。今天别把它当主货，最多作为"跑通包"里的一个附件说明。证据：[gstack](https://github.com/garrytan/gstack)

- **泛写"AI 用法大全"类内容**：今天素材里的用法都很具体（PPT、报销、读书数据），泛写反而没有钩子。今天只写一个具体场景，比写十个用法更容易成交。
