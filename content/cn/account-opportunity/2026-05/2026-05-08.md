# 今日AI账号商机

## 先看信号

- **Claude 开发者大会动作密集**：M365 插件正式 GA、新推 Dream 记忆功能、算力翻倍——Claude 今天热度明显高于平时，买家搜索意愿会跟着走

- **TRAE SOLO 移动端上线，支持配置第三方 API key**：新工具上线 = 新手涌入 = 有人不知道怎么填 key、怎么接模型，代配置需求今天会有
- **ChatGPT 中文体验被吐槽成梗**：负面情绪在发酵，部分用户今天会主动找平替，Claude 和组合体验包的承接时机到了

## 今日主推

### Claude 进 Office 了，但大多数人还不知道怎么开

Anthropic 今天把 Claude 正式塞进了 Excel、Word、PPT、Outlook。不是 beta 了，是正式版。但对普通用户来说，这件事的麻烦不是"有没有"，而是"怎么开、怎么用、用在哪"。

你今天卖的不是账号本身，卖的是**"帮你在 Office 里把 Claude 跑通"的交付包**。买家拿到的是：Claude 账号 + M365 插件开通说明 + 3 个能直接套用的场景（比如 Excel 数据整理、PPT 大纲生成、Outlook 邮件润色）。

- **发生了什么**：Claude M365 插件今天转正式版，Outlook 进入公测，Claude 正式进入办公场景，不再是"开发者玩具"
- **今天先挂什么**：「Claude 进 Office 跑通包」——账号 + 插件开通步骤 + 3 个 Office 场景模板，定价可以做低价引流款（9-19 元）
- **今天先测什么**：标题测两版——①「Excel 里直接用 Claude，不用切网页」②「Claude 进 Office 了，帮你开通+教你用」，看哪个点击更高
- **售后风险**：中等。插件本身是官方的，但账号地区限制可能影响插件激活，说明里要提前写清楚"需要账号本身支持对应地区"，别承诺100%跑通

## 平替机会

- **ChatGPT 中文体验差口碑在发酵** → 今天适合挂「Claude 平替体验号」，主打"不会说奇怪的话、中文更自然"，低价体验款，9 元起试水
- **Claude Code 速率翻倍，但很多人不知道自己的号有没有这个权限** → 卖「Claude Pro 账号 + 权限说明包」，帮买家搞清楚自己买的号能不能用 Code 功能，这是今天的差异化卖点
- **TRAE SOLO 移动端上线，支持自填 API key** → 卖「TRAE 配置包」：帮买家填好第三方模型 key、跑通移动端，适合不想自己折腾的人，轻服务，代配置收费
- **GPT + Claude 双模型对照体验包** → 今天 ChatGPT 被吐槽、Claude 被热议，正好做一个「两个号都给你，自己对比」的组合体验包，卖的是对比感，不是单号

## 闲鱼新品

- **「Claude 进 Office 了，帮你开通+教你用 Excel/PPT/Word」** — 今天最应该先挂的新标题，热度窗口就在今明两天
- **「ChatGPT 中文太奇怪？试试 Claude，中文更顺」** — 借负面情绪做平替引流，低价体验号，9 元起，今晚就能挂
- **「TRAE 手机版配置第三方模型，帮你填好 key 跑通」** — 新工具上线当天挂，搜索量最高，代配置轻服务，交付快、售后边界清楚
- **「Claude + GPT 双号对照体验包，自己选哪个更好用」** — 反常识卖法：不推荐哪个更好，卖的是"让你自己试完再决定"，降低决策门槛，适合犹豫型买家

## 今天别碰

- **Claude Dream 记忆功能相关的账号卖法** — 这个功能是 Platform 控制台的开发者功能，普通买家用不到，硬卖会带来大量售后问题，今天别碰

- **纯 GPT Pro 账号直卖** — 今天 ChatGPT 中文体验负面情绪在发酵，单卖 GPT Pro 号转化会比平时低，不是今天的主角
