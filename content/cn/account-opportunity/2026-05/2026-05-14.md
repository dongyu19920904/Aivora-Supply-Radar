- **Claude Code 限额临时放宽 → Claude 体验入口今天可以主推**。Anthropic 官方调整了 Claude Code 的程序化调用额度，说明之前有人被卡住。今天挂 Claude 账号或体验入口，可以在文案里加一句"限额刚调整，现在进来正好"，降低买家的观望心理。卖法：Claude 体验号 + 上手说明，售后风险低。

- **knowly + NotebookLM 双入口对照包**。买家今天的真实需求是"我想解读视频和论文，但不确定哪个更适合我"。你可以把两个入口打包成一个对照体验包，定价略高于单号，卖的是"先对比再决定"的确定感。交付：两个入口 + 一页使用对比说明。售后风险低。

- **Gemini 安卓配置包**。Gemini Intelligence 落地三星/Pixel 之后，会有一批人想知道"我的手机能不能用、怎么开"。这不适合卖账号，适合卖一个"Gemini 安卓上手包"——开通路径 + 功能说明 + 常见问题。定价低，交付快，售后边界清楚。

## 今天别碰

- **带 bug 标签的早期工具入口**：今天有多个工具被公开标注"还有不少 bug、等后续更新"，这类货现在挂上去售后必然高，先观察一个版本再说。
- **Gemini 账号直卖**：Gemini Intelligence 今天热度高，但功能落地在特定机型，买家拿到账号后发现自己手机不支持，退款纠纷概率大。今天只适合卖配置说明包，不适合卖账号本身。
- **农业遥感论文相关的"支付/地区限制"方向**：候选素材里那条 arXiv 农业论文和账号卖货没有实质关联，强行包装成支付限制机会会让买家看不懂，今天跳过。
