- 今天先测什么：测"Claude 宕机备用"这个标题钩子，看点击和私信量，不要先测单卖 Claude 号

## 平替机会

- **DeepSeek 永久折扣 → 今天是测低价组合包定价的好时机**：DeepSeek-V4-Pro API 折扣转永久，成本端降了，可以把 Claude + DeepSeek 组合包定价压低一档，做"先试后定"的低价引流款。不要只卖 DeepSeek 单号，组合卖才有溢价空间。参考：[橘鸦AI早报 2026-05-23](https://imjuya.github.io/juya-ai-daily/issue-99/)

- **Gemini 平替体验号**：Claude 每次炸，Gemini 都会被顺带搜一波。今天可以挂一条「Claude 用不了？Gemini 直接上手」的平替体验号，标题不要写 Gemini 功能，写"今天能用、不用折腾开通"。售后风险低，适合新手先试一单。

- **ChatGPT 场景搭售包**：[Codex 帮服装店复制销冠](https://x.com/dotey/status/2057835088692256912) 这个案例说明，非技术买家已经在用 ChatGPT 做具体业务场景。今天可以卖"ChatGPT 账号 + 某一个场景的上手模板"，比如"门店话术整理包"或"客服回复模板包"。买家拿到的是结果，不是账号本身。

- **风控避坑说明包**：Claude 频繁炸、Anthropic 涨价预期升温，这两个信号叠在一起，有一批人会开始担心"我现在买的账号还能用多久"。可以做一个「AI账号避坑说明」的轻服务包，写清楚哪些账号今天风险低、哪些要观察、遇到封号怎么切换。卖的是确定感，定价可以低，但私信转化率会高。

## 今天别碰

- **单卖 Claude 账号**：今天 Claude 有宕机信号，单卖 Claude 号售后风险直接升高。买家买了用不了会立刻找你，今天不适合主推，改成组合包或平替包才能控住售后

- **支付/地区限制类纯技术说明包**：候选主题里的支撑素材是眼科 VQA 论文，和支付限制没有实质关联，这个方向今天证据不足，别硬写成主推，先放着

- **封号迁移包（今天单独主推）**：候选主题里封号信号的支撑素材是自动驾驶事件相机论文，同样和封号没有直接关联。封号迁移包可以作为组合包的附件说明，但今天不适合单独作为主推挂出去，证据太弱
