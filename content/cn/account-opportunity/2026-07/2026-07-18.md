## 今日主推

### [Claude Code 上手包：帮买家把 Claude 从"买了但没跑通"变成"今天就能用"](https://github.com/Graphify-Labs/graphify)

买 Claude 账号的人越来越多不是因为看懂了，而是因为周围人在用。但大部分人买完账号不知道下一步，graphify 这类工具出现说明"Claude + 编程场景"的配置门槛比以前高了一截。这正好是你的机会——不是卖工具名，而是把"买账号 → 配置好 → 今天能跑第一个任务"这条路替买家铺好，卖成一个跑通包。

- 发生了什么：Claude Code 生态工具密集出现（graphify 支持代码知识图谱、ruflo 支持多 Agent 协调），说明用 Claude 做编程/写作 Agent 的用户需求在增长，但配置路径变复杂了，买家"买了不会用"的比例也在上升
- 证据来源：[graphify - Claude Code 原生支持的代码知识图谱工具](https://github.com/Graphify-Labs/graphify)、[ruflo - Claude Code 原生集成的 Agent 元框架](https://github.com/ruvnet/ruflo)
- 可信度：中
- 是否今天能挂闲鱼：是
- 目标买家：买了 Claude 账号但没跑通第一个任务的人；想用 Claude 做编程助手但不知道怎么配置的人
- 商品组合：Claude 账号 + 上手教程 + 第一个任务跑通说明（场景选编程助手/写作/总结）
- 闲鱼标题方向：
  - `买了Claude账号用不上？这包帮你今天就跑通第一个任务`
  - `Claude账号+上手包 | 编程/写作/总结 三个场景配置说明`
  - `Claude不会配置？买账号送跑通教程 当天能用`
- 今天先挂什么：主挂"Claude账号+上手包"组合，价格区间比纯账号高15-30元，卖的是跑通感
- 今天先测什么：测"买了用不上"这个钩子标题的点击率，和"三个场景配置说明"这个交付描述的转化率
- 教程/交付物：一页 PDF 或截图说明——①Claude 账号登录步骤；②选一个场景（写代码/写作/整理资料）的基础 Prompt；③常见报错和解决方法；④售后边界说明（账号问题找我，配置问题看文档）
- 售后风险：低
- 售后边界：账号登录问题包售后；配置效果和模型能力不承诺；"跑通"指能正常提问和拿到回复，不包含定制化场景调优
- 今天最小动作：写一版闲鱼商品文案 + 截一张"Claude账号登录成功 + 完成第一次对话"的截图作为封面图，今晚上架测试

## 平替机会

- **多模型对照体验包**：DeepSeek IPO 热榜发酵，有一批人正在重新考虑"国产 vs 海外模型怎么选"。这时候卖单账号不如卖对比体验——Claude 体验号 + DeepSeek/Kimi 免费入口 + 一张对比选择表，定价比单卖 Claude 账号贵10-20元，卖的是"帮你选，不用自己试"。证据来源：[DeepSeek IPO 消息 - 36氪](https://www.36kr.com/p/3899475392906880)。今天可以试挂，售后风险低。

- **Gemini 体验入口 + 场景说明包**：今天 Gemini 没有账号波动或涨价信号，但它一直是"想用 Google AI 但不知道怎么开通"这类买家的常见需求。先挂一版低价体验号，配一页"Gemini 能做什么/不能做什么"的简单说明，作为闲鱼低价引流款，观察问询量再决定是否加量。证据来源：[Google Gemini 官方推文](https://x.com/GeminiApp/status/2078182419203776923)。是否今天能挂：观察，先挂一版看看询价频率。

- **"从 GPT 换到 Claude/Gemini" 迁移说明包**：有用户因为 GPT 涨价或额度问题开始找替代，这类人不缺入口，缺的是"迁移后能不能接上原来的工作流"的确定感。做一份迁移清单：原来用 GPT 做什么任务 → Claude/Gemini 怎么对应 → 哪些能直接替换，哪些有差距。可以单独卖，也可以搭售在账号里。售后风险低，交付明确。

## 今天别碰

- **封号/风控应急包**：今天的封号素材来源是博彩广告转发，完全不是账号波动信号。没有真实的封号证据，不要今天主推"封号后的平替包"——挂了容易被买家追问"哪里在封？"答不上来会直接影响信誉。今天观察，等真实信号再说。

- **镜像站长期稳定包装**：今天没有镜像站爆红或波动的真实信号，不要凭空把镜像入口写成"稳定备用通道"硬卖，售后风险高，问题一旦出现退款压力大。

- **单纯卖 graphify/ruflo 工具入口**：这两个是 GitHub 开源项目，不是账号商品，直接把项目名写进闲鱼标题没有人会搜。要转化的话只能做成"帮你配置 Claude Code 环境"的轻服务，售后边界要说清，不然问题会很多，今天不做主推。
