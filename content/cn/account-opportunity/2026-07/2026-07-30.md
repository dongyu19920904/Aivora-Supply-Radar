## 今日主推

### [Gemini 今天进车了——国内想试的人先买这个入口](https://x.com/GeminiApp/status/2082513350060351616)

Waymo 新车上线，Gemini 官方大刷存在感。对普通中文用户来说这不是新功能能用上的事，但"Gemini 今天又上热搜了"会带来一批临时好奇流量——他们不会自己注册，绕不过支付，但今天就想试一试。

这是低门槛体验号最好卖的节点：不需要跟用户讲 Gemini 有多好，只需要给他们一个今天就能打开的入口。

- 发生了什么：Gemini 官方宣布进入 Waymo 车舱 UI，官推转发刷屏，今天中文圈 Gemini 搜索热度短暂抬升，好奇买家增多但自注册门槛依然存在
- 证据来源：[Google Gemini 官方推文（Waymo 联动）](https://x.com/GeminiApp/status/2082513350060351616)
- 可信度：中
- 是否今天能挂闲鱼：观察
- 目标买家：看到 Gemini 刷屏想尝鲜、但没有境外支付卡的人；以及正在用 ChatGPT 想找备用入口的人
- 商品组合：Gemini 低价体验号 + 登录说明 + 与 ChatGPT 对比一页纸
- 闲鱼标题方向：
  - `不会注册 Gemini？直接买入口，今天能用`
  - `ChatGPT 贵，先试试这个 Google AI 号`
  - `Gemini 体验号｜附登录说明，新手直接上手`
- 今天先挂什么：一版低价体验号（9-19元区间），附 PDF 或截图登录说明，写清可以用几天、不续费不退款
- 今天先测什么：标题「不会注册 Gemini」vs「ChatGPT 贵先试试这个」，看哪个问询多
- 教程/交付物：登录步骤截图、常见报错 FAQ、与 GPT 场景对比一页（写作/翻译/编程三个场景各一句对比）
- 售后风险：低
- 售后边界：体验号有效期内可用，登录问题提供一次答疑，不承诺长期稳定，不换号不退款
- 今天最小动作：今晚先挂一条低价体验号，写两版标题，明天看哪版问询多再决定要不要加库存

## 平替机会

- **Claude 搭售包：openwork 今天上了 Trending，不是让你卖 GitHub，是让你卖"帮你把 Claude 工作台跑起来"的上手包。** 买家麻烦是：知道 Claude 能写代码审查、能做团队协作，但不知道怎么配置、怎么跑起来。你能卖的是：Claude 账号 + openwork 安装说明 + 第一个场景跑通截图。闲鱼标题方向：`Claude 帮你做代码审查——买号送跑通教程` / `不会配置 Claude 工作台？买这个直接有`。[openwork 项目地址](https://github.com/different-ai/openwork)，售后风险低，今天能挂。

- **多模型组合体验包：今天 Claude + Gemini 同时有信号，正好试挂一个"两模型对比体验包"。** 卖点不是某一个好，而是"买一次，自己选哪个顺手"。内容：Claude 体验号 + Gemini 体验号 + 一页对比表（写作/编程/日常问答三行）。定价比单独买两个略低，但单价高于单号。闲鱼标题：`Claude vs Gemini 哪个好用？买这个对比包，自己试` / `两个 AI 号一起买，省得纠结`。售后边界写清楚：各自有效期内可用，不混用、不叠加。售后风险低，今天可以先试挂。

- **Claude Code 使用场景搭售包：graphify 这类工具在跑 Claude Code 场景，说明有一批人正在用 Claude Code 但不知道怎么配合其他工具用。** 可以卖：Claude Code 账号 + 配合 graphify / openwork 的上手说明包，定位"买号顺便拿到一套跑通方案"。不用真的帮人装 graphify，给一张「Claude Code 常见配合工具清单 + 入门步骤」截图就够降售后了。[graphify 项目参考](https://github.com/Graphify-Labs/graphify)。售后风险低，搭售利润有空间。

## 闲鱼新品

- **标题实验一：把 Gemini 的入口价值写成"备用保险"而不是"体验尝鲜"。** 试挂：`ChatGPT 出问题时备用的 Google AI 号` / `主力用 GPT，备一个 Gemini 不亏`。目标是正在用 ChatGPT 但担心账号波动的买家，客单价可以略低，做复购逻辑。

- **标题实验二：把 Claude 账号写成"代码/写作专用"而不是"AI 账号"。** 试挂：`写代码用 Claude，效果比 GPT 强——附入门说明` / `做内容创作的看过来，Claude 比 GPT 好用的场景`。目标是有具体场景需求的买家，比泛泛卖账号更容易成交。

- **组合新品方向：今晚试做一版"三模型选择包"说明页（不需要真的打包三个账号），只做一张对比图：GPT / Claude / Gemini 各适合干什么，配合任一账号销售。** 买家在比较的时候你多一张图，成交率会提升，售后也低。

- **反常识试挂方向：卖"不用自己选模型"的决策服务。** 挂一条：`不知道买 GPT 还是 Claude 还是 Gemini？告诉我你要干嘛，我给你推一个`。收费 5-10 元，交付一段私聊建议。这个不是主卖，但能承接今天多模型热度带来的选择困难买家，也能转化成账号成交。今天可以先试发一条。

## 今天别碰

- **今天那条"封号"信号是赌博广告，不是真实账号风控。** 不要用它做封号迁移包的主推，证据不成立，写出去被买家追问会很尴尬。封号方向今天观察，有真实信号再做。

- **GPT/OpenAI 账号今天没有直接波动信号。** Grok 4.6 定档是 Grok 的事，AI 联名信是政策新闻，都不是"今天 GPT 账号出了问题"的信号。用这个做 GPT 涨价 / 支付限制主推会显得牵强，买家问一句就穿帮。今天 GPT 方向跟着组合包做配角就行，别单独主推。

- **不要今天就卖 Waymo 车载 Gemini 教程包。** 这个功能国内用户真的用不到，买家如果追问怎么在车里用会变成高售后，今天 Gemini 信号的价值只在"带热搜"，不在功能本身。卖入口，不卖车载功能。
