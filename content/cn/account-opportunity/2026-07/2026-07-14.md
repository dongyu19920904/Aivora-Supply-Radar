## 今日主推

### [Claude 设计场景搭售包——账号+装好说明，今天就能挂](https://github.com/nexu-io/open-design)

open-design 把本地设计引擎开源了，原型、落地页、PPT、视频全能出，但跑起来要自备 Claude Code 或 Cursor 账号。买家的麻烦不是找不到工具，是有了工具不知道怎么配、配好了不知道从哪个场景下手。你今天卖的不是账号本身，是「账号 + 装好 + 第一个场景跑通」。

Claude Fable5 访问期刚延到 19 日，五天窗口，买家找入口的理由更足。现在挂一版搭售包，标题写场景结果而不是模型名，今晚就能试单。

- 发生了什么：open-design 开源上线，BYOK 支持 Claude Code / Cursor / Gemini；Claude Fable5 访问期延至 19 日，短期入口需求窗口明确
- 证据来源：[open-design（GitHub）](https://github.com/nexu-io/open-design)、[Claude Fable5 延期（AIBase 日报）](https://www.aibase.com/zh/news/29551)
- 可信度：中
- 是否今天能挂闲鱼：是
- 目标买家：想用 AI 做设计稿、落地页、PPT 的人；有 Claude/Cursor 账号但装了不会用的人；想在 19 日前试一次 Fable5 的人
- 商品组合：Claude Code 体验账号 + open-design 安装说明（截图 3-5 张）+ 一个场景跑通截图（落地页或 PPT 示例）
- 闲鱼标题方向：
  - `用 Claude 生成落地页/PPT，配号+装好+教程，拿到就能跑`
  - `AI 做设计不会配？帮你装好 Claude，直接出 HTML/PDF 文件`
  - `Claude Fable5 窗口期还剩几天，账号+上手包一起拿`
- 今天先挂什么：Claude 体验账号 + open-design 装好说明 + 落地页场景跑通截图，定价走低价试水款（9-19 元体验版）
- 今天先测什么：标题 A「用 AI 生成落地页」vs 标题 B「Claude 账号+装好教程」——看哪个点击来的人问得更具体
- 教程/交付物：一页 open-design 安装步骤截图 + 一个场景跑通录屏（30 秒够），说清账号登录后第一步做什么，常见报错写两条 FAQ
- 售后风险：低
- 售后边界：账号交付后登录问题负责一次；open-design 本地安装提供说明截图，不包代装；场景能否跑通取决于买家本地环境，说明里提前写清
- 今天最小动作：写一页装好说明（截图 3-5 张）+ 改两版标题 + 挂低价体验款，今晚上线

## 平替机会

- **[Cursor / Windsurf 对比体验号](https://github.com/x1xhlol/system-prompts-and-models-of-ai-tools)**：system-prompts 项目把 Cursor、Windsurf、Kiro、Replit 全收录，说明买家正在认真比较选哪个。今天适合挂「Cursor/Windsurf 体验号 + 对比选择说明」，标题写「不知道选哪个？先用这个试一个月」，售后风险低，今天能挂
- **Claude 迁移包（Fable5 窗口期限定版）**：窗口到 19 日，买家有紧迫感但不熟悉 Claude 怎么用。做一个「从 GPT 切换到 Claude 的上手包」，只写「换了账号第一天该干什么」。交付物：账号 + 迁移 FAQ + 5 个常用场景对照表。可信度中，今天能挂，卖法和主推不同（迁移包 vs 搭售包）
- **Gemini Studio 低门槛体验号**：[open-design](https://github.com/nexu-io/open-design) 同样支持 Gemini BYOK，Claude 装不起来的买家会转来找 Gemini 入口。挂一个「open-design 跑不动 Claude？Gemini 版也能用」的平替体验号，接安装失败的流量。先小范围试挂，不作主推

## 闲鱼新品

- **「AI 帮你做 PPT / 落地页，账号+教程一起拿」**：不提模型名，只写结果，买家一看就懂。可搭在 open-design 搭售包下面，也可以单独跑一条测试标题，今天就能试挂
- **「Claude 账号买了不会用？我帮你装好第一个场景」**：搭售类轻服务标题，不承诺长期稳定，只承诺今天装好跑出一个结果。定价走服务款（29-49 元），利润比纯账号高，卖法是搭售利润款
- **「多模型对比体验包：Claude + Cursor，各用一周再决定」**：两个账号打包卖，降低买家决策压力。适合观望型买家，今天先小范围挂一款看有没有人来问——这个方向是组合体验型，和前两条卖法不同
- **「AI 工具对比卡片免费看，买账号前先看这张表」**：用 [system-prompts 项目](https://github.com/x1xhlol/system-prompts-and-models-of-ai-tools) 收录内容做一张工具对比卡，免费挂在商品主图里引流，搭售账号包出售，低价引流款逻辑
