## 今日主推

### [Claude 录屏学技能上线，不会配的人今天就需要有人帮跑一遍](https://www.36kr.com/p/3906459567068544)

Anthropic 昨天在 Claude 桌面端塞了一个新功能：录屏 + 说几句话，Claude 自动把你的操作固化成一个可反复调用的 Skill。听起来很实用，但普通用户第一步就会卡死——桌面端怎么下、Cowork 在哪、录了没反应怎么办。

这不是技术圈的事，这是买家今天的真实麻烦。你卖的不是新闻，是"我先跑通一遍，你照我的说明做，或者把需求发我，我帮你配好"。

今天先挂的不是原账号直卖，是"Claude 账号 + 新功能跑通说明包"的搭售款，测试有没有人冲这个功能来买账号。

- 发生了什么：Anthropic 7月21日在 Claude 桌面端 Cowork 菜单上线「Record a Skill」，录屏+语音讲解后自动生成可复用 Skill，普通用户大量卡在安装和配置环节
- 证据来源：[Claude重磅上新：录屏+语音，一键蒸馏Skill替自己干活](https://www.36kr.com/p/3906459567068544)
- 可信度：中
- 是否今天能挂闲鱼：观察
- 目标买家：已有 Claude 账号但不知道怎么用新功能的人；想让 AI 帮自己固化工作流但不知道从哪入手的小白
- 商品组合：Claude 账号 + Record a Skill 跑通说明包；或单卖"代跑通服务"——买家说需求，你帮录一版 Skill 演示交付
- 闲鱼标题方向：「Claude 出新功能不会用？帮你配好直接上手」／「你不用自己摸索——Claude 录屏蒸馏 Skill 跑通包」／「Claude 新功能帮你设置好，不会安装也没事」
- 今天先挂什么：先挂"Claude 账号 + 新功能上手包"搭售款，中低价，标题写买家麻烦而不是功能名
- 今天先测什么：发一条朋友圈/社群问答："Claude 刚出了录屏学技能功能，有人试过吗？不会的可以问我"，先看有没有人接，再决定要不要做代跑通服务
- 教程/交付物：录一个 2-3 分钟屏录：怎么找 Cowork 菜单 → 怎么开始录制 → 录完 Skill 在哪找 → 怎么调用。配一页 FAQ：录屏没反应怎么办 / 生成的 Skill 能不能在手机端用 / 出错了怎么重来
- 售后风险：中
- 售后边界：说明包只保证演示版流程能跑通，不承诺买家的具体业务场景 100% 生成正确；账号稳定性不在服务范围内
- 今天最小动作：先录一个自己跑通 Record a Skill 的短屏录，发到社群或朋友圈，问有没有人要跑通包，不用先挂商品

## 平替机会

- **[Gemini 低价尝鲜入口](https://t.me/aigc1024/22407)**：技术圈在骂，但实际用量大、覆盖广，普通用户根本没在意那些骂声。这个反差是钩子——有人看到吐槽后会好奇"它到底能不能用"，今天就能接这波好奇流量。挂一个「不知道 Gemini 能不能用？先花小钱试一下」的低价体验号，售后边界写清：体验版不承诺长期稳定，试用为主。

- **Claude + Gemini 双模型对照体验包**：今天同时有 Claude 新功能热度和 [Gemini 讨论](https://m.okjike.com/originalPosts/6a605ce09044d15af2ede8ab)，包成一单刚好：「一次买两个入口，Claude 做工作流、Gemini 跑搜索文档，买了自己对比」。买家不用判断哪个好，你替他做了选择。两个号各自独立，账号问题分开处理。

- **Grok 风控期的备用替代包**：[X 上 Grok 风控讨论](https://x.com/dotey/status/2079796164111606041)信号偏弱，不适合今天主推，但可以先在社群里问一句"有在用 Grok 的吗？最近账号有没有问题"，收集反馈，观察期先备好 Claude/Gemini 平替说明，信号强了再包成迁移包。

- **「今天用哪个 AI 更稳」筛选说明文档**：把 Claude 新功能、Gemini 舆论分化、Grok 风控话题三件事压缩成一页对比表——今天想做什么 → 用哪个 → 怎么开通 → 注意什么。挂成低价文档或搭售内容，买家看完自己能选，你的售后压力最低。

## 闲鱼新品

- **Claude 轻服务标题实验**：同一个"帮你跑通"的方向，今晚先挂两版标题对比看哪个问的人更多。版本 A：「Claude 出新功能了，帮你录屏配好 Skill 直接用」；版本 B：「不会用 Claude 新功能？配置说明包今天发」。哪个被点进来就把哪个做成主推款。

- **Gemini 反差钩子标题**：利用"技术圈骂但普通用户没感觉"这个落差，试挂：「被骂最多的 AI，这些人还在抢着用——Gemini 体验入口」。有点反常识，但今天就能上架试，看有没有好奇点进来的。

- **「AI 账号选不好」组合新品**：不需要备齐所有成品号，把 Claude / Gemini / ChatGPT 三个选项包成"选择指南 + 低价体验入口"的说明包，标题：「不知道买哪个 AI 账号？先看这个对比包」。售后极低，文档一次写好，可以一直卖。

- **Claude Skill 代录服务试水**：买家说需求，你帮他录一个操作流程交付 Skill 演示文件 + 使用说明。不需要卖账号就能挂，买家有 Claude 账号就能用你的交付物。这个方向比较新，今天先私聊或社群试水，不要一上来就公开挂高价。
