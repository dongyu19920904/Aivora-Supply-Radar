# 今日AI账号商机

## 先看信号

- **Claude Code 起源故事在传**：Anthropic 联合创始人 Ben Mann 讲了 Claude Code 怎么从一个 VS Code 插件做出来的，这篇在中文推特圈刷屏。不是新功能，但是带起了一波"Claude Code 到底怎么用"的好奇流量——有人想看，就有人想买入口。
- **Claude Code 生态工具在涌现**：graphify、ruflo 这类支持 Claude Code 的周边项目正在冒头，说明用 Claude Code 的人变多了，但会配好用起来的人还是少数。
- **今天没有实质封号/风控信号**：候选主题里的"封号/风控"条目来源是空间原生时代文章，和封号完全不沾边。可信度低，今天不用跟。
- **GPT/OpenAI 那条支撑素材也跑偏了**：纺织机融资、公众号排版工具，都和账号卖法无关。今天 GPT 方向没有新鲜信号，不做主推。

## 今日主推

### [Claude Code 搭售包：账号+跑通说明，卖给"想用不会配"的人](https://x.com/dotey/status/2074369382965268918)

Ben Mann 那篇 Claude Code 诞生记今天在中文圈大量转发。不是新功能，但效果很好：让一批原本对 Claude Code 半信半疑的人，突然来了兴趣。他们不是开发者，他们是看完觉得"好像挺厉害，我能用吗"的普通人。

这波人今天会去搜怎么用 Claude Code，搜到的全是英文配置教程。这就是缺口——账号搭配一份"装好跑通"的说明，今天就有人愿意买。

卖点不是账号本身，是"你不用自己踩坑，账号进门就能跑"。

- 发生了什么：Anthropic 联合创始人讲 Claude Code 诞生故事在中文推特大量传播，带起一波非开发者的好奇心和入门需求
- 证据来源：[Claude Code 诞生记 - @宝玉 转译](https://x.com/dotey/status/2074369382965268918)
- 可信度：中
- 是否今天能挂闲鱼：是
- 目标买家：看到 Claude Code 新闻、想试用但不知道怎么开通和配置的非开发者；或者已经有 Claude 账号但从没用过 Code 功能的人
- 商品组合：Claude 账号 + Claude Code 上手说明（文字版） + 常见问题 FAQ；进阶版可加一份"3个最能立刻用的场景截图"
- 闲鱼标题方向：
  - `Claude Code 怎么用？账号+新手跑通说明，买了当天能上手`
  - `不会配 Claude Code？账号+安装说明包，省掉两小时踩坑`
  - `Claude 编程助手入门包，含账号+场景教程，不会用退差价`
- 今天先挂什么：一款"Claude 账号 + Code 功能上手说明"的搭售商品，定价比裸账号高 10-20 元，主打省折腾
- 今天先测什么：测标题里"省掉踩坑"和"当天上手"哪个更容易被点开；测买家问的第一个问题是"账号怎么买"还是"装了怎么用"
- 教程/交付物：一页文字说明（怎么登录 + Code 功能在哪 + 第一个任务怎么发）；可加 3 张截图或一段 1 分钟录屏演示
- 售后风险：低
- 售后边界：账号正常登录为交付完成；Code 功能可用为验收标准；买家自己删账号、泄露密码、超出额度限制不在售后范围内
- 今天最小动作：改一版现有 Claude 账号标题，加"含 Code 上手说明"；写一页 200 字以内的跑通说明文档，截 2 张图，挂上去

## 平替机会

- **组合体验包方向**：今天没有特定模型出问题，但 Claude Code 热度起来会带一批比较型买家——"Claude Code 和 Cursor 哪个更值？"这类问题会变多。可以做一个"[Claude + Cursor 对比体验包](https://github.com/Graphify-Labs/graphify)"，两个账号/入口打包，附一张简单对比表（各自适合什么场景）。卖点是"先试再定，不用猜"。售后边界写清楚：两个账号分别独立，不混用不保证额度。

- **Gemini 低门槛尝鲜方向**：Claude Code 火了之后，有一类人会觉得"太复杂了，有没有更容易上手的编程 AI"。Gemini CLI / Google AI Studio 正好接这个需求。挂一个"Gemini 编程助手体验入口 + 新手说明"，定价低，买家上手门槛低，售后少。标题可以试：`不想折腾 Claude Code？Gemini 编程助手更适合新手，含入口说明`

- **Claude 续费/迁移说明包方向**：有一批人已经有 Claude 免费号，现在想升级用 Code 功能，但不知道怎么操作。可以做一个"Claude 升级路线说明包"——不卖账号，卖说明。内容：免费版 vs 付费版功能对比、升级方式、支付受限的备用路线。这种纯教程包售后极低，适合作为引流款挂在搭售商品旁边。

- **"Claude Code 避坑说明"单品**：刚好今天热度在，做一个独立的"Claude Code 上手前要知道的 5 件事"说明文档，单独定个低价挂着。不卖账号，卖信息差。买家问的是"这东西值不值得开通"，你帮他决策。

## 闲鱼新品

- **换标题实验**：现有 Claude 账号商品，今晚试挂两版新标题：
  - A 版（痛点型）：`Claude 账号一直登录不上？附新手常见问题说明`
  - B 版（场景型）：`用 Claude 写代码/改文案，账号+场景教程，当天可用`
  - 观察 24 小时，看哪版询盘更多

- **"多模型对比体验包"新品**：Claude + ChatGPT 两个入口打包，附一张"分别适合什么任务"的对照卡片。不要写成"哪个更强"，写成"各自适合什么人"。标题：`ChatGPT vs Claude 对比体验包，各买一个先试，不用猜哪个值`

- **"AI 编程助手新手入门包"（教程款）**：不绑定账号，卖一份 PDF 或图文说明：Claude Code / Cursor / Gemini CLI 三个选哪个？每个适合什么水平的人？这种定价低、售后近乎零，适合作为引流和建立信任的第一单。

- **"Claude Code 场景包"搭售升级款**：现有 Claude 账号商品，加一个配套的"3个典型使用场景截图+说明"，把商品价格小幅上调，测试买家愿不愿意为"更具体的结果"多付一点。

## 今天别碰

- **"封号/风控紧急备货"方向**：今天没有任何可靠的封号或风控信号，候选来源是"空间原生时代"文章，完全对不上。用这个去渲染紧迫感，买家一问就露馅，直接砸口碑。今天别碰。

- **GPT/OpenAI 强推款**：今天 OpenAI 方向的候选素材（纺织机融资、公众号排版）和账号卖法毫无关系，强行往上靠只会写出牵强的东西。没有新鲜信号就别硬凑，今天 Claude 信号更实。

- **graphify 项目直接卖**：graphify 是个技术工具，把它直接写成商品标题（"知识图谱工具账号"之类）买家不知道你在卖什么。它的价值是作为"Claude Code 能做什么"的佐证，适合出现在教程说明里，不适合做商品标题主词。

## 今日动作

- **先发什么**：发一条朋友圈/社群消息：「Claude Code 这两天好多人问，但真正会配好用起来的很少。我整了一个账号+跑通说明包，当天能上手，有需要私我」
- **先上什么新品**：Claude 账号 + Code 功能上手说明搭售包，比裸账号定价高 15 元左右
- **先改什么标题**：把现有 Claude 账号商品其中一条改成「Claude Code 怎么用？账号+新手说明，省掉两小时踩坑」
- **先写什么教程**：200 字以内的"Claude Code 上手前三步"——登录在哪、功能在哪、第一个指令怎么写
- **先录什么**：1 分钟录屏：打开 Claude 账号 → 找到 Code 入口 → 发第一条指令 → 看到结果。不用剪辑，原始录屏即可
- **先卖哪一款**：Claude 账号 + 上手说明搭售款（低售后、可快速交付、今天有流量）
- **先避开什么坑**：不要在今天没有实质风控信号的情况下，发"账号不稳定赶快备货"类文案——今天信号不支持这么说，发了容易被买家反问，反而掉信任
