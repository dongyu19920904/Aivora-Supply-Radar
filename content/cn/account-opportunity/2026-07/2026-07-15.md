## 今日主推

### [Gemini 进 Chrome 了，想尝鲜的人今天会集中来搜](https://x.com/GeminiApp/status/2077082020572991835)

Gemini 正式内嵌进 Chrome，在英国今天上线，功能是总结网页、跨标签问答、对比内容。消息出来后，中文用户里一定有一批"听说好用但不知道怎么开"的人冒出来——这些人不是要买 Google One，他们就是想先体验一下。

今天主推的不是 Google One 会员，而是"低门槛进去先试试"的 Gemini 体验入口包。售后边界写清楚，教程配好，今天就能挂。

- 发生了什么：Gemini 深度集成 Chrome，Google UK 今天正式宣布上线，功能实用、话题热，中文用户跟进搜索会有延迟效应，今明两天是上架窗口期
- 证据来源：[Google Gemini 官方推特：Gemini in Chrome launches today in the UK](https://x.com/GeminiApp/status/2077082020572991835)
- 可信度：中
- 是否今天能挂闲鱼：是
- 目标买家：听说 Gemini 但从没用过、不知道怎么开通、想先低价体验的中文用户；以及用 GPT 用腻了想换换口味的人
- 商品组合：Gemini 体验号 + 登录说明 + Chrome 插件使用截图 + 常见问题FAQ一页纸
- 闲鱼标题方向：
  - `不用翻墙教程 / Gemini 体验号 / Chrome 直接用 / 买了直接发`
  - `GPT 用腻了试试这个 / Gemini 低价尝鲜 / 含上手说明`
  - `Google AI 助手体验入口 / 附新手使用说明 / 当天交付`
- 今天先挂什么：一版 9-18 元低价体验号，标题用第二条方向，先测点击
- 今天先测什么：标题里带"GPT 用腻了"还是"Gemini 尝鲜"哪个问询多
- 教程/交付物：Chrome 登录截图 + 3 步激活说明 + 常见卡点 FAQ（"为什么我打开没有 Gemini 侧边栏"这类）
- 售后风险：低
- 售后边界：账号交付后登录问题协助一次，功能效果不做承诺，不保长期可用
- 今天最小动作：写一版商品文案 + 配一张 Chrome 侧边栏截图 + 挂上去先看问询量

## 平替机会

- **Grok 用户今天情绪不稳，DeepSeek 平替入口可以小范围试挂。** 马斯克认了隐私泄露，[36氪报道](https://www.36kr.com/p/3895147864947970)今天热榜在顶。卖法：DeepSeek 体验号 + 一页"Grok 跑路后我改用这个"的切换说明。标题方向：`马斯克出事了 / 不想用 Grok 了 / DeepSeek 平替 / 含迁移说明`。售后风险低，今天可以先挂一版观察问询。

- **Claude 账号搭售：gstack 配置包可以包装成"Claude 多角色工作流跑通包"。** [gstack](https://github.com/garrytan/gstack) 是个 Claude Code 配置集合，23个角色分工，对小白来说就是"不用自己想提示词"。卖法：Claude 账号 + gstack 跑通包 + 使用说明。目标买家是想用 Claude 做项目管理或产品工作流但不知道怎么配置的人。售后风险中，今天先做说明包，不急着挂账号。

- **Gemini + DeepSeek 双模型对照体验包。** 两个都是"GPT 平替"话题里的常客，今天同时有热度。可以做一个"两个都试试再决定用哪个"的低价组合体验包，19-29 元，含两个账号/入口 + 一页对比说明（各自擅长什么场景）。闲鱼标题：`GPT 太贵了 / 这两个哪个更好用 / 含体验号+对比说明`。售后风险低，是今天可以直接试挂的新组合。

- **Claude 轻服务：代筛镜像入口 + 说明包。** Claude 直连国内依然麻烦，有持续的"买了不会用"问题。可以做一版"我替你找好能用的入口，你直接登录"的轻服务说明，私信成交，不在闲鱼主页写死具体镜像地址。售后边界：提供当时可用的入口和截图，稳定性不承诺。

## 闲鱼新品

- **新标题实验：把"体验号"改成"入口"。** 直接测"Gemini 浏览器入口 / 含登录说明 / 当天发"和"Gemini 体验号 / 附新手教程"两版哪个问询更多，今晚挂，明天看数据。

- **组合新品：三模型横评包。** ChatGPT + Gemini + DeepSeek，做一个"用同一个问题测三个 AI，附对比截图"的体验包。卖点是买家不用自己注册三个，买了直接看结论。定价 19-39 元，闲鱼标题：`三个 AI 谁更好用 / 一单都试了 / 含账号+对比截图`。

- **今天可以试的新卖点角度：主打"不踩坑版"。** 最近 Grok 出事、各种账号波动，买家对"安不安全、会不会被封"越来越敏感。可以在商品说明里加一行"本号风控逻辑说明 + 常见封号原因说明"，把避坑信息写进交付物，提升成交信任感，不额外收费但可以写进标题：`附避坑说明 / Gemini 体验入口 / 买了不踩坑`。

- **教程包独立卖一版。** 把"怎么用 Gemini 做工作总结 / 网页对比 / 多标签问答"做成一个 PDF 或飞书文档，单独定价 3-9 元，也可以作为搭售附件。买账号的人不一定会用，买教程的人可能顺手也买账号。两条线今天都可以挂。

## 今天别碰

- **封号/风控迁移包今天别硬推。** 今天的封号素材是无效信号（博彩广告帖子），没有真实封号波动证据，不要用这个做主推，挂上去也问不了几单，还容易被买家反问"哪里封了"显得不专业。

- **Claude 代配置服务今天别在闲鱼主页挂公开链接。** gstack 的目标用户是有点技术背景的人，在闲鱼找这个服务的人很少，公开挂成本不低、问询质量差。适合在社群私聊成交，或者先发一条朋友圈试探。

- **瑞幸吸管热度别硬往 AI 账号上靠。** 素材本身是消费品营销，强行关联闲鱼 AI 账号选题逻辑生硬，买家看不懂，今天不值得用这条素材做什么。
