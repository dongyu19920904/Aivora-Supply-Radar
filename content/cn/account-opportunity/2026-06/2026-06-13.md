## 今日主推

### [Claude 跑通包：帮你配好直接用，不用自己排错](https://github.com/garrytan/gstack)

gstack 这个项目今天在 GitHub 传开了，是一套完整的 Claude Code 多角色配置——23 个工具，CEO、设计师、QA 全有。开发者看了觉得香，小白看了完全不知道从哪里开始。

这个信息差就是你今天能卖的东西。买家不是不想用，是不知道怎么跑通。你帮他配好、测好、交付一份说明，他直接上手，这就是今天的单。

- 发生了什么：Claude Code 完整配置方案流传，有需求但大多数人跑不起来
- 证据来源：[gstack - GitHub](https://github.com/garrytan/gstack)
- 可信度：高
- 是否今天能挂闲鱼：是
- 今天先挂什么：「Claude 代配置 · 买了直接跑，不用自己折腾」轻服务商品
- 今天先测什么：在闲鱼挂一版，标题强调"配好交付"不强调工具名，看今晚有没有人来问
- 售后风险：低
- 今天最小动作：写一版商品文案，卖点只写"帮你跑通、交付说明、当天答疑"，不写 Claude Code 技术词

## 平替机会

- **Codex 用量规则改了，有人想换工具** → 今天适合挂「Codex 用不顺手？Claude 代码能力体验号」组合，[来源](https://www.v2ex.com/t/1219847#reply0)。不是说 Codex 坏了，是习惯被打断的人会找替代。卖 Claude 体验号或 Claude + Gemini 双号组合体验包，定价低，售后边界清楚，今天就能试挂。

- **Gemini 小商家功能上线，但开通有门槛** → 国内用户自己搞 Google 账号麻烦，[Gemini 官方](https://x.com/GeminiApp/status/2065527198946337253) 功能在扩但入口不通。今天适合挂「Gemini 体验号 · 国内直接用」，写清楚"省去注册绑卡折腾"，低价尝鲜款，目标是第一次没用过的人。

- **Claude + Gemini 双模型对比体验包** → 两个信号今天都有，但各自单独卖说服力一般。组合成「两个都试一次，看哪个更适合你」，低价引流款，买家拿到的是对比体验而不是盲买。售后风险低，今天可以先做一版商品描述测试反应。

## 闲鱼新品

- **标题实验 A**：「帮你配好 Claude 多角色工作流，买了当天能用」→ 不写 gstack，不写 SDK，写结果。适合挂在闲鱼服务类，今晚先测一版看问询量。

- **标题实验 B**：「Codex 更新用不惯？这里有 Claude 代码平替体验号」→ 蹭 Codex 改版节点，买家是被打断工作流的人，今天情绪最高，今晚值得试一版。

- **新组合**：「AI写代码三件套体验包 · Claude + Gemini + 说明，选一个留着用」→ 三个入口打包低价卖，买家自己选，你的售后压力最小。先做商品文案草稿，不用今天全部备货，先看有没有人咨询。

## 今天别碰

- **封号/风控方向**：今天 Telegram 素材全是赌博广告噪音，没有真实的 AI 账号封号信号。今天别用这个方向做标题或商品，容易写成无中生有，买家问起来答不上来。

- **Codex 账号直卖**：用量规则刚改，卖家自己可能也没摸清新规，今天别主推 Codex 账号，售后风险高，先观察两天规则怎么稳定再说。

- **gstack 直卖"完整配置包"**：如果你自己没跑通，别直接卖打包资料，售后会很难收场。今天只卖"代配置服务"或"跑通后交付说明"，把售后边界卡死。

## 今日动作

- **先发什么**：发一条朋友圈/社群消息，说"Claude 工作流配置跑通了，需要帮配的来找我"，先摸一下有没有人问
- **先上什么新品**：Claude 代配置轻服务，闲鱼上挂"买了当天跑通"版本
- **先改什么标题**：原来写着"Claude 账号"的商品，今天改成「帮你配好直接用 · Claude 代码工作流 · 当天交付」
- **先写什么教程**：不用写长教程，先做一张"交付说明"截图，写清楚你能配什么、交付什么、答疑几次，这就是商品主图

- **先卖哪一款**：Claude 代配置轻服务，低价引流款，今天第一单目的是验证有没有人问
- **先避开什么坑**：今天别碰封号话题（素材是垃圾信息）、别卖没跑通的资料包、别把 Codex 账号主推出去
