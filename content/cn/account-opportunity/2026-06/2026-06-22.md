## 今日主推

### [Codex 额度规则乱了，今天是卖"省心组合包"的好时机](https://www.v2ex.com/t/1221715#reply3)

V2EX 上有 Codex 5x 用户发现：明明昨晚额度只剩 13%，今早莫名回到了 43%。规则说不清，截图也没留。这种"用着用着搞不清还剩多少"的感觉，最容易让人想找个替代或补充方案。

今天不是卖 Codex 本身，是卖"Codex 不够用的时候、Claude Code 能补上"这个组合逻辑。买家的痛点是：主力工具额度不稳，想有个备选不耽误事。

- 发生了什么：Codex Pro 用户额度出现不明原因回升，规则透明度差，用户摸不准使用节奏
- 证据来源：[Codex 的周额度怎么还会增加？](https://www.v2ex.com/t/1221715#reply3)
- 可信度：中
- 是否今天能挂闲鱼：是
- 今天先挂什么：「Codex 不够用时的备份方案——Claude Code 跑通包，含配置说明+上手模板」
- 今天先测什么：低价组合体验包（Codex + Claude 双入口说明），定价在 9-19 元区间，测试有没有人问"我 Codex 用完了还能怎么继续"
- 售后风险：低
- 今天最小动作：写一版商品文案，主打"额度不稳不慌，备用方案帮你接上"，今晚挂上观察问询量

## 平替机会

- **Claude Code 配置跑通服务**：ruflo 框架在 GitHub 有热度，但大多数买家不会自己配。今天可以挂一个"帮你把 [Claude 智能体](https://github.com/ruvnet/ruflo) 跑起来"的代配置服务，限定交付内容：配置好、跑一次、给说明。售后边界清楚，不承诺后续维护。可信度中，今天先发社群试一下。

- **多模型对照体验包（Codex + Claude + Gemini 三选二）**：Codex 额度不稳，正好做"先试再定用哪个"的组合包。不用全给，就两个账号入口+各自上手说明，定价 15-29 元。买家拿到的是：今天就能开始用，不被某一个模型卡住。

- **Claude 入口+场景模板搭售**：不只卖账号，搭一份"3个常用场景的 Claude Prompt 模板"。买家收到的不只是账号，而是"打开就能用"的成套入口。标题改成「Claude账号+开箱即用模板，买了就会用」，试挂观察。

## 今天别碰

- **封号/风控方向**：今天来源是赌博垃圾转发，完全没有可信的封号/风控信号。用这个做卖点，买家一问证据你根本说不清，今天直接跳过。
- **Codex 原账号直卖**：额度规则不透明、重置机制不稳，现在卖 Codex 账号本身，买家买回去搞不清楚怎么用、能用多少，售后必然找你。今天改成卖"组合包"或"备份方案"，不要单推 Codex 账号。
- **技术框架介绍贴**：ruflo 是开发者工具，直接写成"这个框架很厉害"没人在闲鱼买单。要卖的是你帮他配好这个框架的服务，不是框架本身。
