# 今日AI账号商机

## 先看信号
- Claude Code 被逆向后，飞书开放 CLI 工具，所有 AI Agent 都能调飞书能力
- 开源语音输入法 Prompt 曝光，买家开始关注配置包而不是纯工具
- 搭售包需求升温：有账号但不会配、不会用的人在找现成方案
- 场景化交付开始跑通：账号+说明+截图的组合包比单卖账号好成交

## 今日主推
### Claude 账号+飞书配置包

飞书刚开放 CLI 工具，Claude Code 现在能直接调飞书的文档、日历、群消息、多维表格。买家有 Claude 账号但不知道怎么接飞书，今天正好卖配置包。

- 发生了什么：飞书开放了 AI Agent 调用能力，Claude Code 可以直接操作飞书全家桶
- 今天先挂什么：Claude 账号+飞书配置说明+场景截图（创建文档、管理日历、发群消息）
- 今天先测什么：先挂"Claude 接飞书配置包"，标题写"Claude 直接操作飞书文档日历群消息 配置包"
- 售后风险：配置说明清楚就行，不涉及长期维护，买家自己操作

## 平替机会
- Claude 账号+飞书场景包：比单卖 Claude 账号多赚配置费，买家省折腾
- GPT Pro 账号+语音输入配置：开源 Prompt 曝光后，买家想要现成配置而不是自己研究
- 多模型组合包+场景模板：Claude、GPT、Gemini 三个账号+各自适合场景的说明
- 迁移包：从 GPT 迁到 Claude 的配置对照+场景替换说明

## 闲鱼新品
- "Claude 接飞书配置包 创建文档管理日历发群消息"
- "AI 语音输入配置包 GPT/Claude 现成 Prompt"
- "Claude Code 飞书场景包 账号+说明+截图"
- "三模型场景对照包 GPT/Claude/Gemini 各自适合干什么"

## 今天别碰
- 纯开源项目名：飞书 CLI、语音输入法项目名不适合直接当商品标题
- 纯技术逆向内容：Claude Code Web 逆向分析不适合卖给小白
- 长期维护承诺：飞书 API 变化、开源项目更新都不可控，别承诺长期有效

## 今日动作
- 先发什么：Claude 账号+飞书配置说明，先录一个 3 分钟演示视频（创建文档、查日历、发群消息）
- 先录什么：手机录屏，展示 Claude Code 调飞书的三个场景，配上文字说明
- 先卖哪一款：Claude 账号+飞书配置包，定价比单卖账号高 15-30 元，测试搭售接受度
