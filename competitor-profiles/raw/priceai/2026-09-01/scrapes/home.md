# PriceAI 首页原始审计记录

- URL: https://priceai.cc/
- 采集时间: 2026-09-01（Asia/Shanghai）
- 方式: Playwright 真实浏览器，1440×1000 与 390×844
- 状态: 桌面/手机均 HTTP 200，无横向溢出
- 页面高度: 桌面 3,679px；手机 6,895px

## 可核验页面结构

- 顶部可关闭公告条，承接社群和产品反馈。
- 桌面主导航：首页、卡网订阅、官方订阅、官方 API、中转 API、指南、批发合作。
- 手机只保留菜单、品牌与主题切换，完整导航收进菜单。
- H1: `AI 低价卡网订阅与中转 API 比价雷达`。
- 主文案先解释“把哪些购买路径放在同一入口”，而不是先展示数据规模。
- 第一组 CTA: `先选购买路径`、`直接看有货低价`。
- 三条购买路径：订阅新手、资深买家、开发接入。
- 四个模块：卡网订阅、官方订阅、官方 API、中转 API。
- 后续依次说明数据来源、库存和更新时间、交付售后边界、FAQ、赞助商。

## 体验事实

- 首页只承担分流，不把完整报价表和复杂筛选塞进首页。
- 标题、解释、主 CTA、购买路径形成单一路径。
- 桌面使用居中导航和三列任务卡；手机自然变成单列。
- 品牌绿只承担强调和状态，不在整页铺大色块。
