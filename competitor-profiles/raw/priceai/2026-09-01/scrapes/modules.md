# PriceAI 其他模块原始审计记录

- 采集时间: 2026-09-01（Asia/Shanghai）
- 页面: `/official-prices`、`/wholesale`、`/commercial`、`/api-transit`、`/guides`
- 16 个 PriceAI 桌面/手机审计用例全部 HTTP 200，无横向溢出。

## 批发合作

- 把“批量采购需求”和“源头供给”明确拆成两个入口。
- 表单要求方向、标题、真实内容、联系方式和可选证明链接。
- 明示只记录并人工核验，不承诺担保或撮合。

## 商业合作

- 明确可售广告位、适合人群、适合服务、展示形式和素材标准。
- 广告位跟随用户场景：全站公告、首页生态、底部赞助、中转 API、官方 API。
- 对投放素材、文案、安全区和落地页有统一规范。

## API 中转

- 标题区先给更新时间、样本数、主要模型最低倍率。
- 正文解释倍率、稳定性、小额试用和审核边界。
- 申请收录与使用说明直接在首屏。

## 指南

- 独立文档站结构，桌面有目录与页内导航，手机折叠目录。
- 内容围绕购买任务：价格差异、官方订阅、支付方式、卡网风险、ChatGPT 获取方式、API 中转比较。
- 每篇指南都有清晰的下一篇和返回工具入口。
